# Optional Claude statusline

Merge `.agentkit/templates/claude-statusline.json.example` into project `.claude/settings.json` only when a statusline is desired. The installer copies the script into `.agentkit/templates/statusline/`; the example launcher locates that project root from nested working directories.

The Node implementation renders a Codex-style line from the JSON Claude Code passes on stdin: `model effort · session name · 5h N% left · weekly N% left · tokens used · Context N% used · directory · branch`. Rate limits appear only for claude.ai subscription plans after the first response; fields Claude Code omits are skipped. When a local Codex CLI has session logs (`$CODEX_HOME/sessions`, default `~/.codex/sessions`), a second row `Codex 5h N% left · weekly N% left · tokens used · Context N% used` follows. Limits come from the newest log of any project; tokens and context come from the newest Codex session that ran inside the current project, such as a `kit-autopilot` handoff, and are hidden when there is none. The example sets `refreshInterval` so the line keeps updating while Claude waits on a background Codex run. It uses only Node built-ins by default. Set `AGENTKIT_CCUSAGE=1` in the host environment only to use an already installed `ccusage` executable to append the active block cost. It never invokes a package installer or fetches a tool automatically, and subprocess lookups have bounded timeouts.

Statusline configuration remains optional; installing core does not replace an existing statusline. The legacy source `.claude/statusline.js` is a thin launcher of this canonical script.
